## What the `v2/` / `v3/` split means

- **`test/features/v2/`** — FDC3 2.2 wire-protocol surface: user/app/private channels,
  broadcast, event listeners, intents (raise, raise-for-context, find, result), apps
  (metadata, open, findInstances), heartbeat, and disconnect/cleanup behavior.
- **`test/features/v3/`** — FDC3 3.0 wire-protocol surface covering the same areas, with
  3.0-shaped payloads (e.g. richer context/intent metadata) and additional scenarios that
  only apply under 3.0.

Both trees are run by the default profile in `packages/sail-headless-agent/cucumber.yml`
(`npm test` in that package). The generated section above lists the exact scenario counts.
